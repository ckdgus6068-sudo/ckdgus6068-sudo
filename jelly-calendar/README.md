# 젤리 캘린더 (Jelly Calendar)

삼성 갤럭시에서 쓰는 안드로이드 캘린더 앱입니다. 할 일을 시간 길이만큼의 말랑한 “젤리”로 만들어 요일 칸에 자유롭게 넣고, 그날 못 한 젤리는 화면 아래 보관함에 모았다가 주말 같은 다른 날로 옮겨 채웁니다.

## 주요 기능

- **젤리 블록**: 길이(시간)만큼 크기가 정해지는 블록입니다. 가만히 있을 때는 숨 쉬듯 살짝 출렁이고, 누르면 눌리며, 끌고 가면 손가락 반대쪽으로 늘어졌다가 놓는 순간 “퐁” 하고 튕기며 자리를 잡습니다.
- **상자 보기**: 하루를 검은 상자 하나로 보여 줍니다. 그날의 젤리가 시작 시간 순서대로 위에서 떨어져 서로 눌리며 쌓이고, 오래 걸리는 일일수록 젤리가 큽니다. 젤리마다 이름을 크게, 시작 시각과 길이를 작게 적습니다. 앱을 열면 이 화면이 먼저 나옵니다.
- **주간·일간 보기**: 시간표 형태입니다. 주간 보기는 7개 요일 칸을 한눈에 보여 주고, 일간 보기는 하루를 크게 보여 줍니다. 옆으로 밀면 이전·다음 주(일)로 넘어갑니다.
- **사용법 화면**: 처음 실행할 때 한 번 저절로 열리고, 오른쪽 위 메뉴(⋮)의 “사용법”이나 설정에서 다시 볼 수 있습니다. 화면 위쪽 안내 줄에는 지금 보기에서 쓸 수 있는 조작이 요약되어 나옵니다.
- **글씨체**: 기본값 “말랑”은 젤리 이름과 제목에 둥글고 굵은 Bagel Fat One을, 나머지 글자에 Pretendard를 씁니다. 설정의 “화면”에서 “깔끔”(모두 Pretendard)이나 “휴대폰 글꼴”로 바꿀 수 있습니다. 한국어 문장은 단어 중간이 아니라 띄어쓰기에서 줄이 바뀌도록 처리했습니다.
- **완료 표시**: 젤리를 두 번 톡 하거나 꾹 눌렀다 떼면 완료됩니다. 아래에서부터 진한 색이 물처럼 차오르고 체크 표시가 붙습니다. 같은 동작을 한 번 더 하면 완료가 취소됩니다.
- **보관함**: 하루가 지나도록 완료하지 못한 젤리는 자동으로 화면 아래 보관함으로 내려갑니다. 원래 자리에는 “놓침” 점선 자국이 남습니다. 보관함의 젤리를 꾹 눌러 원하는 날의 원하는 시간에 끌어다 놓으면 됩니다.
- **반복 젤리**: 매일, 평일, 주말, 또는 원하는 요일마다 같은 시간과 길이로 자동으로 깔리는 기본 젤리입니다. 처음 실행하면 예시로 “아침 러닝(매일 06:00, 50분, 기상 연동)”이 들어 있으며, 지워도 됩니다.
- **삼성 시계 연동**: 아래 “삼성 시계 연동 방식과 한계”를 참고해 주세요.
- **백업**: 설정 화면에서 전체 데이터를 JSON 파일로 저장하고 다시 불러올 수 있습니다.

## 공유 젤리 (함께 쓰는 한 달 달력)

정한 사람과 함께 보는 한 달 달력입니다. 상자·주·일 화면의 내 일정은 지금처럼 휴대폰 안에만 있고, 공유 탭에 올린 젤리만 서버(Firebase)에 저장됩니다.

- **갤럭시:** 앱 위쪽의 ‘공유’ 탭에서 엽니다.
- **아이폰:** 사파리에서 `https://ckdgus6068-sudo.github.io/ckdgus6068-sudo/share/`를 열고 ‘홈 화면에 추가’를 누르면 앱처럼 쓸 수 있습니다. 앱스토어용 앱은 애플 개발자 등록과 맥이 있어야 해서 웹 앱으로 만들었습니다.
- **같이 쓰기:** 한 사람이 ‘새 공유 달력 만들기’를 누른 뒤 메뉴(⋯)의 ‘상대 초대하기’로 8자리 초대 코드를 보냅니다. 코드는 7일 동안 쓸 수 있습니다.
- **할 수 있는 일:** 날짜를 골라 젤리를 올리고, 이름·날짜·시간·길이·색·완료를 두 사람 모두 바로 고칠 수 있습니다. 젤리마다 메모를 주고받을 수 있고, 누가 올리고 고쳤는지 표시됩니다. 상대가 고친 내용은 새로 고치지 않아도 바로 화면에 나타납니다.
- **오프라인:** 연결이 끊긴 동안 고친 내용은 연결되면 자동으로 올라갑니다.

### 구조

- 웹 앱: `docs/share/` (빌드 과정 없이 그대로 GitHub Pages로 공개). Firebase SDK는 `jelly-calendar/share/build.mjs`로 묶어 `docs/share/vendor/firebase.js`에 넣었습니다.
- 서버: Cloud Firestore와 익명 로그인. 접근 규칙은 `jelly-calendar/share/firestore.rules`에 있습니다. 공유 달력마다 무작위 비밀값이 있고, 초대 코드로 그 값을 받은 사람만 들어올 수 있으며, 들어온 사람만 젤리와 메모를 읽고 쓸 수 있습니다.
- 시험: `jelly-calendar/share`에서 `npm ci` 뒤 `npm run test:rules`(보안 규칙 18개), `npm run test:e2e`(두 휴대폰이 한 달력을 함께 쓰는 과정)를 Firebase 에뮬레이터로 실행합니다. GitHub Actions도 같은 시험을 돌립니다.

### 처음 한 번 설정할 것

1. Firebase 콘솔에서 프로젝트를 만들고, Authentication의 ‘익명’ 로그인을 켜고, Firestore 데이터베이스를 만듭니다(위치 `asia-northeast3`, 프로덕션 모드).
2. Firestore의 ‘규칙’ 탭에 `jelly-calendar/share/firestore.rules` 내용을 붙여 넣고 게시합니다.
3. 프로젝트 설정의 웹 앱 `firebaseConfig` 값을 `docs/share/config.js`에 넣습니다. 이 값은 원래 공개되는 값이고, 실제 보호는 2번의 규칙이 맡습니다.
4. GitHub 저장소의 Settings → Pages에서 Source를 ‘Deploy from a branch’로 두고, 이 브랜치와 `/docs` 폴더를 고릅니다.

## 조작 방법

위쪽 “상자 · 주 · 일” 버튼으로 보기를 바꿉니다. 오른쪽 아래(상자 보기에서는 상자 오른쪽 위)의 ‘+’ 버튼으로 새 젤리를 만들고, 보관함의 “+ 할 일”로 날짜 없는 젤리를 보관함에 넣어 둘 수 있습니다.

상자 보기

| 동작 | 결과 |
| --- | --- |
| 젤리를 한 번 톡 | 편집 창 열기 |
| 젤리를 두 번 톡 | 완료 또는 완료 취소 |
| 젤리를 꾹 눌렀다 떼기 | 완료 또는 완료 취소 |
| 젤리를 끌기 | 상자 안에서 잡고 흔들기 |
| 젤리를 상자 밖 위쪽 날짜 칸으로 끌어다 놓기 | 시간은 그대로 두고 그날로 옮기기 |
| 젤리를 아래 보관함으로 끌어다 놓기 | 보관함에 넣기 |
| 보관함 젤리를 꾹 눌러 상자에 놓기 | 그날 빈 시간에 넣기 |
| 빈 곳을 옆으로 밀기 | 전날 또는 다음 날 |

주간·일간 보기

| 동작 | 결과 |
| --- | --- |
| 젤리를 한 번 톡 | 편집 창 열기 |
| 젤리를 두 번 톡 | 완료 또는 완료 취소 |
| 젤리를 꾹 눌렀다 떼기 | 완료 또는 완료 취소 |
| 젤리를 꾹 누른 채 끌기 | 다른 시간, 다른 요일, 보관함으로 옮기기 |
| 젤리 아래쪽 손잡이를 끌기 | 길이(시간) 조절 |
| 빈 칸을 꾹 누르기 | 그 시간으로 새 젤리 창 열기 |
| 위쪽 요일 칸으로 끌어다 놓기 | 시간은 그대로 두고 그 요일로 옮기기 |
| 화면을 옆으로 밀기 | 이전 또는 다음 주(일) |

완료 방식(두 번 톡, 꾹 누르기)은 설정에서 각각 끌 수 있습니다.

## 삼성 시계 연동 방식과 한계

안드로이드가 다른 앱에 열어 주는 알람 기능은 읽기, 추가, 끄기 요청 정도뿐이라서, 젤리 캘린더도 이 세 가지만 사용합니다.

1. **알람 읽기 (알람 → 첫 일과)**: 휴대폰이 알려 주는 “다음 알람” 한 개의 시각을 읽습니다(`AlarmManager.getNextAlarmClock`). 그 알람이 기상 시간대(기본 03:00–12:00) 안에 있으면 그날의 기상 시각으로 기록하고, “기상 연동”을 켠 반복 젤리를 알람이 울린 뒤 여유 시간(기본 10분)부터 차례로 배치합니다. 반복 젤리끼리의 원래 간격은 그대로 유지됩니다.
2. **알람 맞추기 (첫 일과 → 알람)**: 상자 보기나 일간 보기의 기상 카드에서 버튼을 누르면 삼성 시계에 1회용 알람을 추가해 달라고 요청합니다(`AlarmClock.ACTION_SET_ALARM`). 알람 시각은 “첫 일과 시작 − 여유 시간”입니다.
3. **예전 알람 끄기**: 새 알람을 먼저 추가한 뒤, 바뀌기 전 알람(휴대폰이 알려 준 그날의 기상 알람과, 이 앱이 앞서 요청한 알람)을 끄라고 삼성 시계에 요청합니다(`AlarmClock.ACTION_DISMISS_ALARM`, 시각으로 찾기). 1회용 알람은 꺼지고, 반복 알람은 그날 한 번만 건너뜁니다. 새 알람을 먼저 맞추기 때문에 끄기가 실패해도 알람이 사라지는 일은 없습니다. 설정의 “새 알람을 맞추면 예전 알람 끄기”로 끌 수 있습니다.

다음과 같은 한계가 있습니다.

- 알람을 지우거나 시각을 고치는 공개 기능은 없습니다. 그래서 “새 알람 추가 + 예전 알람 끄기”로 옮기는 방식을 씁니다. 삼성 시계가 끄기 요청을 받아 주지 않으면 예전 알람은 직접 꺼야 하며, 이때 기상 카드에 안내가 나옵니다.
- 한 번에 알 수 있는 알람은 “다음 알람” 하나뿐입니다. 그래서 알람을 맞출 수 있는 날도 앞으로 24시간 안에 알람이 울리는 날(보통 내일 아침)로 한정됩니다.
- 알람 목록을 읽을 수 없으므로, 다른 앱이 예약한 알람이 “다음 알람”으로 잡힐 수도 있습니다. 설정 화면에서 그 알람을 어느 앱이 만들었는지 확인할 수 있습니다.
- 확인 필요: 삼성 시계가 “다음 알람” 정보를 제공하는지, “바로 추가” 요청을 확인 화면 없이 저장하는지, 끄기 요청을 받아 주는지는 기기와 One UI 버전에 따라 다를 수 있습니다. 실제 갤럭시 기기에서는 아직 시험하지 못했습니다.

## 설치 방법

휴대폰에서 아래 링크를 누르면 GitHub 로그인 없이 최신 APK가 바로 내려받아집니다.

- 최신 APK: https://github.com/ckdgus6068-sudo/ckdgus6068-sudo/releases/download/jelly-calendar-latest/JellyCalendar.apk
- 릴리스 페이지: https://github.com/ckdgus6068-sudo/ckdgus6068-sudo/releases/latest

1. 링크를 삼성 인터넷이나 Chrome에서 열어 `JellyCalendar.apk`를 내려받습니다.
2. 다운로드가 끝나면 “내 파일” 앱의 다운로드 폴더에서 파일을 누릅니다. 다운로드 알림이나 다른 앱(예: 메신저, Claude 앱)에서 파일을 누르면 설치 화면이 열리지 않을 때가 있으니, “내 파일”에서 여는 방법을 권합니다.
3. “출처를 알 수 없는 앱 설치” 안내가 나오면, 사용 중인 브라우저(삼성 인터넷이나 Chrome)에 설치 권한을 허용한 뒤 설치합니다. Play 프로텍트 경고가 나오면 안내에 따라 설치를 계속 진행합니다. 스토어에 등록되지 않은 앱이라서 나오는 경고입니다.
4. 삼성의 “자동 차단” 기능이 켜져 있으면 설치가 막힙니다. 이때는 설정의 “보안 및 개인정보 보호”에서 자동 차단을 잠시 끄고 설치하세요. 메뉴 이름은 One UI 버전에 따라 조금 다를 수 있습니다.
5. 새 버전도 같은 링크에서 받아 덮어 설치하면 됩니다. 모든 빌드가 같은 서명 키를 쓰므로 데이터가 그대로 남습니다.
6. 설치된 버전은 앱 설정 화면 맨 아래(예: “젤리 캘린더 0.2.12”)에서 확인할 수 있습니다. 빌드할 때마다 버전 번호가 올라갑니다.

릴리스는 `main` 또는 `claude/`로 시작하는 브랜치에 코드가 올라갈 때마다 GitHub Actions가 새로 만듭니다. Actions 실행 결과의 Artifacts에서도 APK를 받을 수 있지만, 그쪽은 GitHub 로그인이 필요합니다.

## 데이터 보관

- 모든 데이터는 휴대폰 안의 앱 전용 저장소에 JSON 파일 하나로 저장됩니다. 쓰는 도중에 앱이 꺼져도 파일이 깨지지 않도록 임시 파일에 먼저 쓴 뒤 바꿔 넣고, 직전 버전을 백업으로 한 부 더 남깁니다.
- 휴대폰을 바꿀 때는 설정의 **백업 파일 저장**으로 파일을 만든 뒤, 새 휴대폰에서 **백업 불러오기**를 사용하세요.

## 개발 정보

- `core`: 일정 규칙만 담은 순수 Kotlin 모듈입니다. 반복 젤리 배치, 보관함 이동, 알람 연동 계산, 겹침 배치, 저장 형식을 담당하며 단위 테스트가 있습니다.
- `app`: Jetpack Compose 화면과 안드로이드 연동(삼성 시계, 파일 저장, 백업)입니다. 젤리의 출렁임은 `ui/jelly`에서 외곽선을 점으로 나눈 뒤 매 프레임 스프링 값으로 밀고 당겨 그립니다.
- 빌드 환경: JDK 17, Android SDK 35, AGP 8.7.3, Kotlin 2.1.0, Compose BOM 2024.12.01, 최소 Android 8.0(API 26).
- 빌드 명령: `./gradlew :core:test :app:assembleRelease`
- 서명 키 `app/jelly-sideload.jks`는 개인 설치용으로 저장소에 공개되어 있습니다. 플레이 스토어에 올릴 때는 별도의 비공개 키를 써야 합니다.
- 상자 보기의 젤리는 `ui/box`에서 점을 고리 모양으로 이은 말랑한 물체로 계산합니다(위치 기반 물리, 넓이 유지 제약). 젤리가 모두 멈추면 계산도 멈춰서 가만히 있는 상자는 화면을 다시 그리지 않습니다.

## 검증 범위

- `core` 모듈의 일정 규칙과 저장 형식은 단위 테스트 50개로 검증했습니다.
- 화면 코드는 데스크톱용 Compose(1.5)로 컴파일하고 실제 글꼴을 넣어 그려서 젤리 모양, 상자 보기, 드래그, 완료 표시, 사용법 화면을 이미지로 확인했습니다. 같은 코드를 Kotlin 2.1 컴파일러로도 컴파일해 보았습니다.
- 안드로이드 APK 빌드는 GitHub Actions에서 수행합니다.
- 실제 갤럭시 기기에서의 동작(특히 삼성 시계 연동과 손가락 조작감)은 아직 확인하지 못했습니다.
