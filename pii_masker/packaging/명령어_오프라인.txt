 개인정보 마스킹 프로그램 - USB 하나로 오프라인 설치하기 (최종본)
==========================================================================

[USB 최종 구조]  ※ E: 는 본인 USB 드라이브 문자로 바꿔 읽기
--------------------------------------------------------------------------
 E:\마스킹 프로그램 만들기\
   ├─ python-3.14.x-amd64.exe     <- (1) 파이썬 설치파일
   ├─ 명령어.txt                   <- (2) 이 파일
   └─ pii_masker\                  <- (3) 프로그램 폴더
        ├─ gui.py, masker.py ...        (코드)
        ├─ offline\wheels\              (패키지 .whl - [준비-3]에서 채움)
        └─ models\easyocr\             (한글모델 .pth - [준비-3]에서 채움)
--------------------------------------------------------------------------


==========================================================================
[준비] 인터넷 되는 PC(vmfort)에서 - USB 채우기
==========================================================================

[준비-1] (1) 파이썬 설치파일 받기
 - vmfort에서 먼저 버전 확인:
python --version
 - python.org/downloads 에서 그 버전의 'Windows installer (64-bit)' 받아
   USB의  마스킹 프로그램 만들기\  폴더에 넣기.

[준비-2] (3) 최신 프로그램 코드 USB에 두기
 - GitHub ZIP을 받아 압축 풀고, 그 안의 pii_masker 폴더를
   USB의  마스킹 프로그램 만들기\  안에 복사(기존 것 있으면 덮어쓰기).
 - 주의: pii_masker 안에 혹시 .venv 폴더가 있으면 삭제(오프라인에서 새로 만듦).

[준비-3] (3) 안에 패키지+모델 채우기  ★가장 중요★
 - easyocr 가 동작하던 cmd 창( 줄 앞에 (.venv) 표시 )에서 아래를 순서대로:

cd /d "E:\마스킹 프로그램 만들기\pii_masker"
pip download pymupdf pillow easyocr -d offline\wheels
if not exist models\easyocr mkdir models\easyocr
copy "%USERPROFILE%\.EasyOCR\model\*" models\easyocr\

 - 확인(둘 다 파일이 보여야 함):
dir offline\wheels
dir models\easyocr

 - offline\wheels 에 pymupdf, pillow, easyocr, torch 등 .whl 들이 있고
   models\easyocr 에 .pth 들이 있으면 USB 준비 끝.


==========================================================================
[설치] 내부망(오프라인) PC에서
==========================================================================

[설치-1] 파이썬 설치
 - USB의 python-3.14.x-amd64.exe 실행 ->
   첫 화면 'Add python.exe to PATH' 반드시 체크 -> Install Now

[설치-2] 프로그램을 PC로 복사
 - USB의 pii_masker 폴더를 바탕화면에 복사(USB에서 바로 돌리지 말 것).

[설치-3] 설치 & 실행
 - 바탕화면 pii_masker 폴더 열기 -> 주소창 클릭 -> cmd 입력 -> Enter
 - 그 검은 창에 아래를 순서대로:

python -m venv .venv
.venv\Scripts\activate
pip install --no-index --find-links offline\wheels pymupdf pillow easyocr
python gui.py

 - 3번째 줄에서 "Successfully installed pymupdf-..." 나오면 성공.
 - 4번째 줄에서 마스킹 프로그램 창이 뜨면 끝.


==========================================================================
[사용법] 프로그램 창
==========================================================================
 1. OCR 엔진을 easyocr 로 변경 (기본 tesseract 이므로 꼭 바꾸기)
 2. '추가'로 PDF 선택
 3. 관련자 명단: '가명' 칸 먼저 입력(필수) -> 이름들/주민번호 -> '추가'
    예) 가명: 피의자1 / 이름들: 여인석 / 주민번호: 631001-1011314
 4. 출력 폴더 선택
 5. '마스킹 실행'
 결과(출력 폴더): 원본_masked.pdf(검은칠본, 이것만 외부 사용),
                 mapping.json(실명 대응표-외부유출 금지), 원본_audit.json


==========================================================================
[문제해결]
==========================================================================
* "No module named 'fitz'"  -> 가상환경 안 켬. 줄 앞 (.venv) 확인. 없으면:
.venv\Scripts\activate

* "Could not find a version that satisfies pymupdf (from versions: none)"
  -> 원인1: offline\wheels 가 비어있음(=[준비-3] 안 함) -> vmfort에서 다시.
  -> 원인2: 파이썬 버전이 vmfort와 다름. 확인:
python --version
     wheels 파일명의 cpXXX 와 버전이 같아야 함(예 cp314 = 3.14).

* 메모리 부족(not enough memory) -> 다른 프로그램 닫고, 실행 전에:
set PII_RENDER_SCALE=1.5
python gui.py

* 설치된 패키지 확인:
pip list
