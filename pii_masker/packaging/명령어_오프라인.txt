==========================================================================
 개인정보 마스킹 프로그램 - 오프라인 설치/실행 명령어 모음
==========================================================================
 읽는 법: [A]는 인터넷 되는 vmfort에서, [B]는 내부망(오프라인 PC)에서 실행.
 cmd 창을 폴더에서 여는 법: 탐색기에서 'pii_masker' 폴더(=gui.py 보이는 곳)를
   열고 → 맨 위 주소창 클릭 → cmd 입력 → Enter.
 ※ 줄 앞에 ::  로 시작하는 건 설명(주석)이라 입력 안 해도 됨.
==========================================================================


[0] 먼저 확인 — 내부망 바탕화면 pii_masker 폴더에서 무엇이 있는지 점검
--------------------------------------------------------------------------
:: (폴더로 이동한 cmd에서)
dir
:: -> gui.py, masker.py 가 보여야 함
dir offline\wheels
:: -> *.whl 파일들(특히 pymupdf, pillow, easyocr, torch)이 있어야 함
dir models\easyocr
:: -> *.pth 파일들이 있어야 함
python --version
:: -> 이 숫자가 vmfort에서 휠 받을 때 버전과 같아야 함(중요)

:: 위 둘(offline\wheels, models\easyocr)이 비어있거나 없으면 -> [A]부터 다시.
:: 둘 다 있으면 -> 바로 [B]로.


==========================================================================
[A] vmfort(인터넷 됨, easyocr 가 돌아갔던 그 환경)에서 "준비물" 만들기
==========================================================================
:: easyocr 가 동작하던 cmd 창(줄 앞에 (.venv) 표시)에서, pii_masker 폴더로 이동해 실행.

:: A-1) 패키지 묶음 내려받기 (torch 포함, 수 GB / 몇 분)
pip download pymupdf pillow easyocr -d offline\wheels

:: A-2) 한글 모델을 프로그램 안으로 복사
if not exist models\easyocr mkdir models\easyocr
copy "%USERPROFILE%\.EasyOCR\model\*" models\easyocr\

:: A-3) 확인 (둘 다 파일이 있어야 함)
dir offline\wheels
dir models\easyocr

:: A-4) 이제 pii_masker 폴더 전체를 USB로 복사해 내부망 바탕화면에 풀기.
::      (offline\wheels, models\easyocr 가 폴더 안에 같이 들어있어야 함)
::      + Python 설치파일(vmfort와 같은 버전)도 USB에 같이 넣기.


==========================================================================
[B] 내부망(오프라인 PC)에서 설치하고 실행하기
==========================================================================
:: 0) Python 설치: 받아온 python-3.x.x-amd64.exe 실행 ->
::    첫 화면에서 'Add python.exe to PATH' 반드시 체크 -> Install Now
::    (vmfort와 같은 버전이어야 함)

:: 1) 바탕화면 pii_masker 폴더에서 cmd 열기(주소창에 cmd) 후 아래 순서대로:

:: 2) 가상환경 만들기
python -m venv .venv

:: 3) 가상환경 켜기  (성공하면 줄 앞에 (.venv) 가 붙음 - 이게 중요!)
.venv\Scripts\activate

:: 4) 오프라인 설치 (인터넷 없이 USB로 가져온 휠로 설치)
pip install --no-index --find-links offline\wheels pymupdf pillow easyocr

::    -> "Successfully installed pymupdf-... pillow-... easyocr-..." 나오면 성공.
::    -> "Could not find a version..." 빨간 오류면: 파이썬 버전이 vmfort와 다른 것.
::       (python --version 으로 확인, 같은 설치파일로 다시 설치)

:: 5) 실행
python gui.py


==========================================================================
[C] 사용법 (프로그램 창이 떴을 때)
==========================================================================
:: 1. OCR 엔진을 easyocr 로 변경 (기본 tesseract 이므로 꼭 바꿀 것)
:: 2. '추가'로 마스킹할 PDF 선택
:: 3. 관련자 명단: '가명' 칸 먼저 입력(필수) -> 이름들/주민번호 입력 -> '추가'
::    예) 가명: 피의자1 / 이름들: 여인석 / 주민번호: 631001-1011314
:: 4. 출력 폴더 선택
:: 5. '마스킹 실행'
:: 결과(출력 폴더):
::   원본이름_masked.pdf  = 검은칠 완료본 (이것만 외부/클로드에 사용)
::   mapping.json         = 가명-실명 대응표 (실명 포함! 외부 공유 금지)
::   원본이름_audit.json  = 무엇을 가렸는지 기록


==========================================================================
[D] 문제 해결
==========================================================================
:: * "ModuleNotFoundError: No module named 'fitz'"
::   -> 가상환경을 안 켠 것. 줄 앞에 (.venv) 있는지 확인. 없으면:
.venv\Scripts\activate
::   -> 그래도면 [B]-4 설치가 안 된 것. 다시 실행하고 메시지 확인.

:: * 메모리 부족(not enough memory) 오류
::   -> 다른 프로그램(크롬/Adobe) 닫고, 실행 전에 해상도 낮추기:
set PII_RENDER_SCALE=1.5
python gui.py

:: * 설치된 패키지 확인
pip list

:: * 한글이 네모(□)로 보임 -> assets\NanumGothic.ttf 가 폴더에 있는지 확인
dir assets
