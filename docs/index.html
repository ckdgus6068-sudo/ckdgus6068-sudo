젤리 캘린더

🍬
할 일을 젤리로오래 걸리는 일일수록 큰 젤리가 돼요. 하루를 상자 하나에 담아 한눈에 볼 수 있어요.
💞
함께 쓰는 달력가족, 연인, 친구와 같은 달력을 보고 젤리마다 메모를 주고받아요. 아이폰도 함께 쓸 수 있어요.
⏰
삼성 시계 알람젤리마다 시작 전에 울릴 알람을 맞출 수 있어요. (갤럭시)
카카오톡 안의 화면에서는 설치 파일이 잘 받아지지 않아요. 아래 버튼을 눌러 크롬이나 삼성 인터넷으로 이 페이지를 다시 열어 주세요. 다른 브라우저로 열기 버튼이 안 되면 오른쪽 아래(또는 위) 메뉴 ⋮에서 ‘다른 브라우저로 열기’를 눌러 주세요.

갤럭시에서 설치하기

개인이 만든 앱이라 플레이스토어 대신 이곳에서 받아요. 그래서 설치할 때 휴대폰이 확인 창을 몇 번 띄우는데, 아래 순서대로 누르시면 돼요.

갤럭시 앱 받기
  1. 위 버튼을 눌러 받아 주세요. 파일을 받을지 묻는 안내가 나오면 ‘다운로드’를 고르시면 돼요.
  2. 다 받으면 알림이나 ‘내 파일 → 다운로드’에서 JellyCalendar.apk를 눌러 주세요.
  3. ‘출처를 알 수 없는 앱’ 안내가 나오면 ‘설정’에서 이 출처 허용을 켠 뒤 돌아와 ‘설치’를 눌러 주세요.
  4. Play 프로텍트 안내가 나오면, 안내 창에서 설치를 이어 가는 버튼(예: ‘무시하고 설치’)을 눌러 주세요. 스토어에 올리지 않은 앱이면 늘 나오는 안내예요.
  5. 설치가 아예 막히면 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠시 끄고 다시 해 보세요. 설치를 마친 뒤에는 다시 켜 두셔도 돼요.

새 버전이 나오면 같은 방법으로 덮어 설치하세요. 쓰던 젤리는 그대로 남아요.

안심하고 쓰셔도 돼요

  • 앱이 쓰는 권한은 시계 알람 맞추기와 인터넷, 두 가지뿐이에요. 연락처, 사진, 문자, 위치는 쓰지 않아요.
  • 내 젤리는 휴대폰 안에만 저장돼요.
  • 공유 달력의 내용은 암호화되어, 서버를 운영하는 사람도 볼 수 없어요. 개인정보 안내
  • 광고도 결제도 없어요.

아이폰에서 함께 쓰기

공유 젤리 열기
  1. 사파리에서 열고, 가입하기 전에 공유 버튼 → ‘홈 화면에 추가’를 눌러 주세요.
  2. 홈 화면의 ‘공유 젤리’ 아이콘으로 열어 아이디로 가입한 뒤, 받은 초대 코드를 넣어 주세요.
