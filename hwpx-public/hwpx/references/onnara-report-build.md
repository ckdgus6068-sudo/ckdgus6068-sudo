# 온나라 행정보고서(행정보고 양식) 빌드 규칙

`assets/onnara-report-template.hwpx` + `scripts/report_builder_onnara.py` 로 만든다.
본문 내용·문체 규칙(구조·기호·내어쓰기·줄길이·▵·관용한자)은 **`onnara-report-style.md`** 를 따른다.

## 양식 구조
날짜 박스 → 제목 박스(HY견고딕 22pt) → 문서요약 박스 → 본문(□◦-※ 4단계) → 붙임 박스.

본문 4단계(양식에서 서식 자동 탐지):
- □ 수준1 (HY견고딕 15pt)
- ◦ 수준2 (문체부 바탕체 15pt)
- - 수준3 (문체부 바탕체 15pt)
- ※ 유의사항 (중고딕 13pt)

## 사용 예시
```python
import sys; sys.path.insert(0, "<스킬폴더>/scripts")
from report_builder_onnara import OnnaraReport
r = OnnaraReport("<스킬폴더>/assets/onnara-report-template.hwpx")
body = [
    r.l1("추진 배경"),
    r.l2("온나라 보고 서식 표준화 필요"),
    r.l3("부서별 서식 상이로 결재 지연"),
    r.note("세부 통계 별도 붙임"),
    r.empty(),
    r.l1("주요 내용"),
    r.l2("보고서 자동 생성 도구 도입"),
]
r.build("/mnt/user-data/outputs/행정보고.hwpx",
        title="제목",
        summary=["◦ 문서요약 첫째 줄", "◦ 문서요약 둘째 줄"],   # 문서요약 박스 자동 채움
        body=body, attach="붙임 문서명 1부")
# 이후 present_files
```
- `title` 은 그대로 제목 박스에 들어간다(양식에 박혀 있던 앞 따옴표는 빌더가 제거 — 제목 앞 `’` 문제 해결).
- `summary` 는 문서요약 박스 내용. 문자열 하나 또는 줄 리스트(보통 `◦` 로 시작하는 1~4줄). 생략(None)하면 ‘문서요약’ 라벨이 남는다.
- `l1/l2/l3/note` 는 마커(□◦-※)와 규정 띄어쓰기를 자동 적용한다.
- ◦/-/※ 는 내어쓰기(기호+한 칸 기준)를 자동 적용한다. 괄호 요약 시작 등으로 어긋나면 `hang=` 으로 조정(예: `r.l2("(현안관리 강화) …", hang=3800)`), 최종 미세조정은 한글에서.

## 규칙
- paraPr/charPr 번호는 코드에 박지 않고 양식 골격(□ 수준 1 등)에서 자동 탐지.
- 저장 직전 참조 검증 — 끊긴 참조 있으면 오류로 막음(빈 페이지 방지).
- linesegarray 제거, 저장 후 fix_namespaces 자동.

## 표 (2~6열)

`r.table(rows, small=False)` 로 만든다. rows[0]=머리행.

- 서식: 맑은 고딕 12pt 가운데 정렬(머리행 볼드). 칸이 부족하면 `small=True` 로 10pt.
- 테두리: 표 상단·하단 굵은 실선(0.5mm), 좌단·우단 선 없음, 내부선 0.12mm 실선.
- 머리행: 배경 #DFE6F7, 아래 테두리 이중 실선.
- 열 너비: 균등 분할하되 첫 열만 좁게(0.7배). 열 수 2~6 지원.
- 표 뒤에는 `r.empty()` 로 빈 줄 하나.

```python
r.table([["구분","대상","현황","조치"],
         ["기획팀","12명","서식 상이","표준화"],
         ["운영팀","10명","서식 상이","표준화"]])
```

표용 borderFill 9종(id 24~32)과 10pt charPr(사용 시)는 빌더가 header에 자동 추가하고,
저장 직전 paraPr/charPr/borderFill 참조를 전수 검증한다.

## 현재 범위(v3)와 한계
- 채움: 제목(앞 따옴표 자동 제거), 문서요약 박스(`summary=`), 본문(□◦-※), 표(2~6열), 붙임 문서명.
- 수동(한글에서 편집): 날짜·부서 박스(양식의 `○○국 / ○○과`), 붙임 ‘1부.’ 등 마무리.
- 표: 위 table() 사용(2~6열). 사진(이미지)은 지원하지 않는다.
- 화면 확인 필요: 제목 글꼴 크기, □◦-※ 단계 들여쓰기·문단 간격은 한글에서 육안 확인 권장.
