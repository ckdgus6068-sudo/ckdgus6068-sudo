# hwpx (일반 배포판)

Claude가 한컴오피스 한글 문서(.hwpx)를 만들고 읽고 편집할 수 있게 하는 스킬입니다. 원본 스킬에서 경찰 수사서류(수사보고서·수사결과보고서) 양식과 빌더, 수사서류 작성 스킬과 연결되는 안내를 모두 뺐습니다.

## 할 수 있는 일

- 기본 보고서 양식(표지·목차·□○―※ 본문)에 내용을 채워 넣습니다.
- 온나라 행정보고서 양식(제목·문서요약·□◦-※ 본문·표·붙임)을 만듭니다.
- 공문(기안문) 작성 규격에 맞춰 문서를 만듭니다.
- 사용자가 올린 .hwpx 양식의 텍스트를 바꿔 넣습니다.

## 구성

- `hwpx/SKILL.md`: 스킬 본문입니다.
- `hwpx/assets/`: 기본 보고서 양식과 온나라 행정보고서 양식입니다.
- `hwpx/references/`: 보고서·공문·온나라 보고서 작성 규격과 HWPX 내부 구조 설명입니다.
- `hwpx/scripts/`: 온나라 보고서 빌더, 네임스페이스 후처리·참조 검증, 표 폭 통일 스크립트입니다.
- `hwpx.zip`: 업로드용 압축 파일입니다. 내부에 `hwpx/` 폴더가 들어 있습니다.

## 설치

- Claude 앱(claude.ai, 데스크톱 앱): Settings → Capabilities에서 ‘Code execution and file creation’을 켠 뒤, Customize → Skills → ‘+’ → ‘+ Create skill’ → ‘Upload a skill’ 순서로 `hwpx.zip`을 올리고 스위치를 켭니다. 일반 사용자용 단계별 안내는 저장소 최상위의 `kakao-install-guide.txt`에 있습니다.
- Claude Code: `hwpx` 폴더를 `~/.claude/skills/` 아래에 복사합니다.

## 알아 둘 점

- 표지 로고 자리는 비워 두었습니다. 기관 로고가 필요하면 한글에서 그림을 바꿔 넣습니다.
- 글꼴은 파일에 포함되지 않습니다. 양식 글꼴(HY헤드라인M, 휴먼명조, HY견고딕 등)이 없는 컴퓨터에서는 다른 글꼴로 보입니다.
- 사진을 넣는 전용 빌더는 없습니다. 온나라 보고서 빌더는 표(2~6열)까지 지원합니다.
