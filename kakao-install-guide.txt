[Claude 스킬 설치 안내]

같이 보낸 zip 파일은 Claude(클로드)에 기능을 더해 주는 ‘스킬’입니다. 한 번 설치해 두면 Claude가 필요할 때 알아서 사용합니다.
- fluent-korean.zip : Claude가 더 자연스럽고 뜻이 분명한 한국어로 답합니다.
- hwpx.zip : Claude에게 한글 문서(.hwpx 파일)를 만들어 달라고 할 수 있습니다.

■ 준비
- Claude 계정(무료 계정도 스킬을 쓸 수 있다고 안내되어 있습니다)
- 설치는 컴퓨터에서 합니다. 인터넷 창에서 claude.ai에 접속하거나 Claude 데스크톱 앱을 쓰면 됩니다.
- 메뉴 이름은 영어로 적었습니다. 화면이 한국어로 나오면 같은 자리에 있는 한국어 메뉴를 누르세요.

■ 1단계: zip 파일을 컴퓨터에 저장
- 카카오톡 PC버전에서 이 대화방을 열고 zip 파일을 저장합니다.
- 압축은 풀지 마세요. zip 파일 그대로 올려야 합니다.
- 맥(Mac)에서 파일이 저절로 폴더로 풀렸다면, 그 폴더를 오른쪽 클릭하고 ‘압축하기’를 눌러 zip 파일로 다시 만든 뒤 올리세요.

■ 2단계: 코드 실행 기능 켜기(처음 한 번만)
- Settings(설정) → Capabilities(기능)로 들어갑니다. 설정은 보통 화면 왼쪽 아래 내 이름을 누르면 나옵니다.
- ‘Code execution and file creation’(코드 실행 및 파일 생성)을 켭니다.
- 이 기능이 꺼져 있으면 스킬이 작동하지 않습니다.

■ 3단계: 스킬 올리기
- Customize → Skills 메뉴로 들어갑니다.
- ‘+’ 버튼 → ‘+ Create skill’ → ‘Upload a skill’을 차례로 누릅니다.
- 저장해 둔 zip 파일을 선택합니다.
- zip 파일이 두 개라면 하나씩 따로 올립니다.

■ 4단계: 켜져 있는지 확인
- Skills 목록에서 올린 스킬 옆의 스위치가 켜져 있는지 확인합니다.

■ 사용법
- 따로 부를 필요 없이 평소처럼 부탁하면 됩니다.
  예) “오늘 회의 내용을 한글 파일로 정리해줘”
  예) “이 안내문 문장을 자연스럽게 다듬어줘”
- 만들어진 한글 파일은 한컴오피스 한글에서 열어 보세요. 양식에 쓰인 글꼴이 컴퓨터에 없으면 다른 글꼴로 보일 수 있습니다.

■ 잘 안 될 때
- 업로드가 안 되면: 압축을 풀었다가 다시 묶은 파일이 아닌지 확인하고, 처음 받은 zip 파일을 그대로 올려 보세요.
- 한글 파일이 만들어지지 않으면: 2단계 설정이 켜져 있는지 확인하세요.
- 회사·단체 계정(Team, Enterprise)은 관리자가 스킬 기능을 허용해야 쓸 수 있습니다.

■ 주의
- 스킬은 믿을 수 있는 사람에게 받은 것만 설치하세요(Claude 공식 안내 사항입니다).
